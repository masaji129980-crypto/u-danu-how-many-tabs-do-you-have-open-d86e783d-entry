# How Many Tabs Do You Have Open? — entry

## The competition

A make.fun bounty with a brutally simple brief: answer the question.
How many browser tabs do you have open right now? No essay, no excuses —
just the number.

## This entry

**73**

Seventy-three tabs. Some are research, some are "I'll read this later"
from weeks ago, and at least a few are the same page opened twice
because the first copy was buried. The number is the confession; the
program simply reports it.

## Running it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Executing the program writes the count to a text file in the directory
named by `MAKEFUN_OUTPUT_DIR` (or `/output` when the variable is
absent).
